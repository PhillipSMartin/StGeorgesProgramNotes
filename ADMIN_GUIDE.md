# Admin Portal Guide

This guide is for people who are new to the St. George's Choral Society program-notes admin portal. The portal manages the languages shown to visitors, the notes in each language, publishing, printing, and language-selection statistics.

## 1. Sign in

1. Open the admin portal at [https://program-notes-display--phillipmartin2.replit.app/admin](https://program-notes-display--phillipmartin2.replit.app/admin).
2. Enter the admin password and select **Sign In**.
3. You should arrive at the **Admin Portal** dashboard.

If you do not have the password, ask the person who administers the site. Do not share the password in the program notes or in a public document.

## 2. Understand the dashboard

The dashboard has these main areas:

- **Supported Languages** — add, disable, reorder, or remove language choices, and open a language's content editor.
- **Translate All Languages** — translate the English program content into every enabled non-English language.
- **Print Program Notes** — prepare all enabled languages for printing.
- **Analytics & Reporting** — view language-selection statistics and archived reports.
- **Security** — change the admin password.

Use **View Site** to return to the public site. Use **Logout** when you are finished, especially on a shared device.

## 3. Edit program notes for one language

1. In **Supported Languages**, select the edit icon beside the language you want to work on.
2. Check the language name at the top of the editor so you know which version you are changing.
3. Edit the available sections:
   - **Introduction** is optional and appears before the program pieces.
   - Each **Piece** has a title, composer, and formatted program notes.
   - **Footer / Attribution** is optional plain text shown after the pieces, such as a note crediting the writer.
4. Use the notes toolbar for bold, italic, underline, lists, text alignment, undo, and redo.
5. Use the up and down arrows on a piece to change its order. Select **Add Another Piece** to add one. The delete button removes a piece; at least one piece must remain in the editor.
6. Select **Preview** to check how the current editor contents will look. The preview includes unsaved changes.
7. Select **Save** to store your edits.
8. If you want the saved content visible to visitors, select **Publish**. If the language was already published, saving edits makes the content a draft, so publish it again after reviewing.

The editor shows **Unsaved changes** when there are edits not yet saved. Save before leaving the page if you want to keep them.

### Publish and unpublish

- **Publish** makes the language's saved pieces, introduction, and footer available on the public program page.
- **Unpublish** hides that language's content from the public program page without deleting it.
- A **Draft** or **Published** label near the language name indicates its current status.

Always preview and check the language-specific text before publishing.

## 4. Translate content

The English content is the source for translation. Add or review the English pieces, introduction, and footer first.

### Translate one language

1. Open the target language's editor.
2. Choose **OpenAI** or **Google Translate** in the **AI Translation** section.
3. Select **Translate**. The translated text is loaded into the editor; it is not published automatically.
4. Review the titles, composer names, notes, introduction, and footer. Machine translation can make mistakes, especially with names and specialized terms.
5. Select **Save**, then **Publish** when the translation is ready for visitors.

Translating and then saving replaces that language's piece list with the translated English pieces. Review any existing translation before saving so you do not overwrite text you want to keep.

### Translate all languages

1. Return to the dashboard.
2. Choose **OpenAI** or **Google Translate** under **Translate All Languages**.
3. Select **Translate, Save & Publish All**, then confirm the prompt.
4. Wait for the completion message. If some languages fail, the message identifies the languages that need attention.
5. Open the affected language pages on the public site and review them.

**Important:** Translate All processes every enabled non-English language. It replaces the existing pieces in each of those languages with a fresh translation of the English pieces, then saves and publishes the results. Do not run it if you need to preserve manually edited translated pieces. Make sure the English source content is final first.

## 5. Manage supported languages

In **Supported Languages**:

- Use the **edit** icon to open and edit that language's program content.
- Use the toggle to enable or disable a language. Disabled languages are not offered to visitors and are skipped by Translate All.
- Use the up and down arrows to change the order in which languages are listed.
- Select **Add Language** to enter its English name, language code, native name, and text direction. Check these details carefully, especially the code and whether the language reads right-to-left (RTL).
- Use the trash icon to remove a language only when you are sure it is no longer needed. This removes it from the supported-language list.

Adding a language makes it active. Add or translate its program content and publish it before expecting a complete public page.

## 6. Print the program notes

1. From the dashboard, select **Print All Notes**.
2. Check the language sections in the print view.
3. Select **Print** and use your browser's print dialog to print or save as PDF.

The print view includes enabled languages that have content, with each language starting on a separate page. It can include draft or unpublished content, so review the print view before distributing it.

## 7. View and export analytics

1. Select **View Analytics** on the dashboard.
2. Choose **Current Statistics** or an archived period from the selector.
3. Use the chart selector to switch between a bar chart and a pie chart.
4. Select **Export PDF** to open the browser's print dialog, where you can print or save the report as a PDF.
5. **Clear & Archive** moves the current statistics into an archive and clears the current period. Confirm only when you are ready to start a new current reporting period; archived periods remain selectable.

Statistics are based on visitors' language selections.

## 8. Change the admin password

1. On the dashboard, select **Change Admin Password**.
2. Enter the current password, then enter and confirm the new password.
3. The new password must be at least six characters and both new-password entries must match.
4. Select **Change Password**.

Store the new password securely and share it only with people who need admin access.

## Quick publishing checklist

- Confirm you are editing the intended language.
- Check spelling, names, piece order, and formatting.
- Use **Preview** before saving.
- Select **Save**, then **Publish** to make your edits visible.
- Visit the public page for that language and confirm the result.
